# KnowFlow AI 数据库设计

## 概述

| 项目    | 说明               |
| ----- | ---------------- |
| 数据库   | PostgreSQL 17    |
| 扩展    | pgvector（向量检索）   |
| 迁移工具  | Flyway（19 个迁移脚本） |
| ORM 层 | MyBatis          |
| 字符集   | UTF-8            |

当前数据库包含 12 张核心表，按功能域分为：用户与认证、知识库与协作、文档与检索、聊天与消息、设置与偏好。

模型供应商、API Key 等敏感配置均在后端加密存储，数据库仅保存密文；前端不直接读写敏感字段。

---

## ER 关系概览

### users（用户）

用户认证与个人信息。密码哈希存储，角色控制权限；头像仅保存 OSS object key 或 preset ID，不存图片二进制。

| 列名                | 类型           | 约束                      | 说明                    |
| ----------------- | ------------ | ----------------------- | --------------------- |
| id                | BIGSERIAL    | PK                      | 用户 ID                 |
| username          | VARCHAR(64)  | NOT NULL, UNIQUE        | 用户名                   |
| password_hash     | VARCHAR(255) | NOT NULL                | 密码哈希                  |
| role              | VARCHAR(32)  | NOT NULL                | 角色（ADMIN / USER）      |
| email             | VARCHAR(254) | —                       | 邮箱（可空，大小写不敏感唯一）       |
| phone             | VARCHAR(32)  | —                       | 手机号                   |
| avatar_object_key | TEXT         | —                       | 阿里云 OSS 头像 object key |
| avatar_preset_id  | VARCHAR(32)  | —                       | 默认头像 preset ID        |
| avatar_updated_at | TIMESTAMPTZ  | —                       | 头像更新时间                |
| created_at        | TIMESTAMPTZ  | NOT NULL, DEFAULT now() | 创建时间                  |
| updated_at        | TIMESTAMPTZ  | NOT NULL, DEFAULT now() | 更新时间                  |

索引：

- uq_users_email_lower_not_null — lower(email) WHERE email IS NOT NULL
- idx_users_avatar_updated — (id, avatar_updated_at)
- idx_users_avatar_preset — (id, avatar_preset_id)

### knowledge_bases（知识库）

知识库是文档的组织容器。

| 列名          | 类型           | 约束                      | 说明                    |
| ----------- | ------------ | ----------------------- | --------------------- |
| id          | BIGSERIAL    | PK                      | 知识库 ID                |
| name        | VARCHAR(120) | NOT NULL                | 知识库名称                 |
| description | TEXT         | —                       | 描述                    |
| status      | VARCHAR(32)  | NOT NULL                | 状态（ACTIVE / ARCHIVED） |
| featured    | BOOLEAN      | NOT NULL, DEFAULT false | 是否精选                  |
| theme_id    | VARCHAR(64)  | —                       | 主题色 ID                |
| created_by  | BIGINT       | FK → users(id)          | 创建者                   |
| created_at  | TIMESTAMPTZ  | NOT NULL, DEFAULT now() | 创建时间                  |
| updated_at  | TIMESTAMPTZ  | NOT NULL, DEFAULT now() | 更新时间                  |

### knowledge_base_members（知识库成员）

知识库的多角色协作权限。

| 列名                | 类型          | 约束                                                   | 说明     |
| ----------------- | ----------- | ---------------------------------------------------- | ------ |
| id                | BIGSERIAL   | PK                                                   | 记录 ID  |
| knowledge_base_id | BIGINT      | NOT NULL, FK → knowledge_bases(id) ON DELETE CASCADE | 知识库 ID |
| user_id           | BIGINT      | NOT NULL, FK → users(id) ON DELETE CASCADE           | 用户 ID  |
| role              | VARCHAR(16) | NOT NULL, CHECK IN (OWNER,EDITOR,VIEWER)             | 角色     |
| created_at        | TIMESTAMPTZ | NOT NULL, DEFAULT now()                              | 加入时间   |
| updated_at        | TIMESTAMPTZ | NOT NULL, DEFAULT now()                              | 更新时间   |

唯一约束：(knowledge_base_id, user_id)

### documents（文档）

用户上传的文档记录。source_bytes/source_text 持久化原始内容用于重新处理。

| 列名                      | 类型           | 约束                                                   | 说明         |
| ----------------------- | ------------ | ---------------------------------------------------- | ---------- |
| id                      | BIGSERIAL    | PK                                                   | 文档 ID      |
| knowledge_base_id       | BIGINT       | NOT NULL, FK → knowledge_bases(id) ON DELETE CASCADE | 所属知识库      |
| original_filename       | VARCHAR(255) | NOT NULL                                             | 原始文件名      |
| content_type            | VARCHAR(64)  | —                                                    | MIME 类型    |
| size_bytes              | BIGINT       | —                                                    | 文件大小（字节）   |
| status                  | VARCHAR(32)  | NOT NULL                                             | 处理状态       |
| error_message           | TEXT         | —                                                    | 错误信息       |
| summary                 | TEXT         | —                                                    | AI 生成的文档摘要 |
| summary_updated_at      | TIMESTAMPTZ  | —                                                    | 摘要生成时间     |
| source_bytes            | BYTEA        | —                                                    | 原始文件二进制    |
| source_text             | TEXT         | —                                                    | 解析后的文本     |
| source_text_updated_at  | TIMESTAMPTZ  | —                                                    | 文本解析时间     |
| embedding_status        | VARCHAR(32)  | NOT NULL, DEFAULT SKIPPED                            | 向量化状态      |
| embedding_error_message | TEXT         | —                                                    | 向量化错误信息    |
| embedding_updated_at    | TIMESTAMPTZ  | —                                                    | 向量化时间      |
| created_by              | BIGINT       | NOT NULL, FK → users(id)                             | 上传者        |
| created_at              | TIMESTAMPTZ  | NOT NULL, DEFAULT now()                              | 创建时间       |
| updated_at              | TIMESTAMPTZ  | NOT NULL, DEFAULT now()                              | 更新时间       |

### document_chunks（文档分块）

文档解析后的文本块，是全文检索和语义检索的基本单元。

| 列名                   | 类型          | 约束                                                   | 说明           |
| -------------------- | ----------- | ---------------------------------------------------- | ------------ |
| id                   | BIGSERIAL   | PK                                                   | 分块 ID        |
| document_id          | BIGINT      | NOT NULL, FK → documents(id) ON DELETE CASCADE       | 所属文档         |
| knowledge_base_id    | BIGINT      | NOT NULL, FK → knowledge_bases(id) ON DELETE CASCADE | 所属知识库        |
| chunk_index          | INTEGER     | NOT NULL                                             | 分块序号（从 0 开始） |
| content              | TEXT        | NOT NULL                                             | 分块文本内容       |
| char_count           | INTEGER     | NOT NULL                                             | 字符数          |
| embedding            | vector      | —                                                    | pgvector 向量  |
| embedding_status     | VARCHAR(32) | NOT NULL, DEFAULT SKIPPED                            | 向量状态         |
| embedding_updated_at | TIMESTAMPTZ | —                                                    | 向量更新时间       |
| created_at           | TIMESTAMPTZ | NOT NULL, DEFAULT now()                              | 创建时间         |

唯一约束：(document_id, chunk_index)
全文索引：GIN on to_tsvector(simple, content)

### document_processing_jobs（文档处理任务）

持久化记录每一次文档处理尝试。

| 列名                | 类型          | 约束                                                                 | 说明     |
| ----------------- | ----------- | ------------------------------------------------------------------ | ------ |
| id                | BIGSERIAL   | PK                                                                 | 任务 ID  |
| document_id       | BIGINT      | NOT NULL, FK → documents(id) ON DELETE CASCADE                     | 目标文档   |
| knowledge_base_id | BIGINT      | NOT NULL, FK → knowledge_bases(id) ON DELETE CASCADE               | 所属知识库  |
| requested_by      | BIGINT      | NOT NULL, FK → users(id) ON DELETE CASCADE                         | 发起人    |
| job_type          | VARCHAR(32) | NOT NULL, CHECK IN (UPLOAD_INDEX,REPROCESS,REBUILD_SEMANTIC_INDEX) | 任务类型   |
| status            | VARCHAR(32) | NOT NULL, CHECK IN (QUEUED,RUNNING,SUCCEEDED,FAILED,CANCELED)      | 状态     |
| progress_percent  | INTEGER     | NOT NULL, DEFAULT 0, CHECK 0-100                                   | 进度百分比  |
| stage             | VARCHAR(64) | —                                                                  | 当前阶段   |
| message           | TEXT        | —                                                                  | 阶段消息   |
| error_message     | TEXT        | —                                                                  | 脱敏错误信息 |
| started_at        | TIMESTAMPTZ | —                                                                  | 开始时间   |
| finished_at       | TIMESTAMPTZ | —                                                                  | 完成时间   |
| created_at        | TIMESTAMPTZ | NOT NULL, DEFAULT now()                                            | 创建时间   |
| updated_at        | TIMESTAMPTZ | NOT NULL, DEFAULT now()                                            | 更新时间   |

| user_id              | BIGINT       | FK → users(id)                              | 所属用户      |

### user_rag_settings（用户 RAG 设置）

用户级别的检索增强生成参数。

| 列名                 | 类型               | 约束                                                   | 说明         |
| ------------------ | ---------------- | ---------------------------------------------------- | ---------- |
| user_id            | BIGINT           | PK, FK → users(id) ON DELETE CASCADE                 | 用户 ID      |
| retrieval_mode     | VARCHAR(32)      | NOT NULL, DEFAULT HYBRID, CHECK IN (HYBRID,FULLTEXT) | 检索策略       |
| semantic_weight    | DOUBLE PRECISION | NOT NULL, DEFAULT 0.7, CHECK 0-1                     | 语义检索权重     |
| fulltext_weight    | DOUBLE PRECISION | NOT NULL, DEFAULT 0.3, CHECK 0-1                     | 全文检索权重     |
| top_k              | INTEGER          | NOT NULL, DEFAULT 5, CHECK 1-20                      | 返回结果数      |
| max_context_chunks | INTEGER          | NOT NULL, DEFAULT 5, CHECK 1-20                      | 注入上下文最大分块数 |
| temperature        | DOUBLE PRECISION | NOT NULL, DEFAULT 0.2, CHECK 0-2                     | LLM 温度参数   |
| created_at         | TIMESTAMPTZ      | NOT NULL, DEFAULT now()                              | 创建时间       |
| updated_at         | TIMESTAMPTZ      | NOT NULL, DEFAULT now()                              | 更新时间       |

约束：semantic_weight + fulltext_weight = 1.0

## 安全设计要点

- 密码：Spring Security 密码编码器哈希存储。
- API Key：AES-256 加密（密钥来自 KNOWFLOW_MODEL_SECRET_KEY）。
- 头像：DB 仅存 OSS object key 或 preset ID。
- SQL 注入防护：MyBatis 参数化查询。
- 脱敏输出：系统诊断不暴露敏感 URL 或凭证。
