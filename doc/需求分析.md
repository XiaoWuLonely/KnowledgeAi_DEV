# KnowFlow AI 需求分析

## 1. 产品定位

KnowFlow AI 是一个智能知识库问答平台。用户上传学习资料、项目文档、产品文档或内部知识材料后，系统会自动解析文档、切分索引，并允许用户基于自己的知识库进行 AI 增强问答。回答需要展示引用来源，方便用户确认答案来自哪些文档片段。

### 核心价值

- 把零散文档整理成可检索、可问答的知识库。
- 让用户用自然语言查询自己的资料，而不是手动翻文档。
- 回答必须有引用来源，强调可信、可追溯、可复核。
- 面向学习、项目管理、产品文档、知识沉淀和轻量团队协作场景。

### 目标用户

- 学生或学习者：上传课程资料、笔记、PDF、Markdown，进行复习问答。
- 项目管理者：上传项目文档、会议纪要、技术方案，基于项目资料快速查找信息。
- 产品/技术写作人员：上传产品文档、用户手册，验证文档覆盖度和检索准确性。
- 轻量团队：共享知识库，多人协作上传和检索。

## 3. 用户流程

### 核心用户旅程

注册/登录 → 创建知识库 → 上传文档 → 等待文档解析和索引 → 进入 Chat 选择知识库并提问 → 查看 AI 回答和引用来源 → 管理会话 → 在 Settings 中配置模型和 RAG 参数

### 详细流程

1. 注册/登录：用户名 + 密码注册，登录后获取 JWT token
2. 创建知识库：输入名称、描述，可选主题色
3. 上传文档：选择文件上传，系统异步处理（解析 → 分块 → 索引 → embedding）
4. 文档索引：后台任务中心展示进度，支持重试和取消
5. RAG 问答：选择知识库进入 Chat，输入问题（可选 @ 指定文档），系统检索相关文档片段（全文 + 语义混合），AI 基于检索结果生成回答，展示引用来源
6. 会话管理：查看历史会话、置顶、删除
7. 设置管理：配置个人模型、API Key、RAG 参数、偏好

## 4. 非功能性需求

### 4.1 性能

- Chat 消息 SSE 流式输出延迟 < 500ms 首 token
- 文档全文检索响应时间 < 1s（中等数据量）
- 语义检索响应时间 < 2s（依赖外部 embedding API）
- 前端首屏加载时间 < 3s

### 4.2 安全

- 所有 API（除 login/register/health）需 JWT 认证
- 用户 API Key AES-256 加密存储，脱敏返回
- OSS 鉴权参数不暴露给前端
- 错误信息脱敏，不泄露堆栈、API Key、内部路径
- 知识库成员权限隔离：VIEWER 只读，EDITOR 可管理文档，OWNER 全部权限

### 4.3 可用性

- 中文界面为主，英文用于导航标签和技术状态
- 支持 375px-1440px 响应式布局
- 移动端单列布局，侧边栏改为抽屉
- 触控目标 ≥ 44px
- 支持 reduced-motion

### 4.4 可维护性

- Flyway 管理所有 DDL 变更
- doc/ 目录只保留三份文档：需求分析、数据库设计、后端系统设计
- 接口概要随功能范围和后端系统设计同步维护，不再单独维护独立接口文档
- 当前不保留后端测试文件；后端变更后以编译、启动和核心接口手动验收为主

### 4.5 数据

- 用户上传文件 ≤ 10MB（后端硬限制，`DocumentController.MAX_FILE_SIZE_BYTES` 与 `spring.servlet.multipart.max-file-size` 保持一致）
- 文档分块大小可配置（默认约 500-1000 字符）
- 全文检索使用 PostgreSQL GIN 索引 + tsvector
- 语义检索使用 pgvector 向量扩展
- 文档原始 bytes 持久化，支持重新处理

## 5. 设计约束

- 不内置 mock 模型服务，用户需提供真实模型配置
- 不伪装有未实现的功能（未来功能必须视觉区分）
- 不对用户隐瞒风险操作（删除等需二次确认）
- 不暴露 API Key、Base URL、JDBC URL 等敏感信息
- Settings 中的配置项必须接入真实后端 API，不做假保存
- UI 不使用 emoji 作为功能图标，使用 Lucide 图标库

---

## 6. UI/UX 设计原则

- 专业智能 SaaS 工作台风格：浅色为主、清爽、克制
- 深色文字高对比度，次级文字使用 slate/neutral
- 卡片圆角 6-8px，按钮和输入框圆角统一
- 动画 150-250ms，仅用于状态转换，不干扰工作
- 状态颜色语义化：绿-成功/已索引，琥珀-处理中/警告，红-失败/危险
- 不使用装饰光球、bokeh、随机渐变块
- 页面不使用卡片套卡片的结构
- 首页非营销页面，直接展示工作台
